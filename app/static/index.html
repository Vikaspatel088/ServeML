DEVELOPER REFERENCE · API

Speak the contract.

A small, versioned API with explicit schemas and predictable errors.

Open FastAPI docs ↗
GETTING STARTEDAuthenticationEndpointsResponsesErrors
01 · ACCESS

Authentication

This local demonstration does not require an API key. Keep the service on a trusted development network; add authentication before exposing it publicly.

02 · INFERENCE

Single prediction

POST/api/v1/predict

Provide the four Iris measurements as positive finite numbers in centimeters.

REQUEST BODY 
{
  "sepal_length": 5.1,
  "sepal_width": 3.5,
  "petal_length": 1.4,
  "petal_width": 0.2
}
POST/api/v1/predict/batch

Use {"instances":[...]} for up to 250 observations. The response includes one model result per row.

GET/api/v1/model/metadata

Returns training and artifact metadata produced by the training pipeline.

GET/api/v1/model

Returns the serving model name, version, and state.

GET/api/v1/metrics

Returns process-local request counts, success rate, latency, uptime, class counts, and recent predictions.

GET/health

Returns service and model readiness. HTTP 200 means ready; HTTP 503 means unavailable.

03 · RESPONSE

Response schema

Single and batch response shapes are defined by the running FastAPI application. Open the generated schema to inspect every field and status code.

Open generated OpenAPI JSON ↗

Use the playground to send a real example and inspect the model response and class probabilities.

04 · ERRORS

Validation & failures

200
SUCCESS

A valid prediction, batch response, model or metrics response, or healthy readiness check.

422
VALIDATION_ERROR

Invalid, missing, out-of-range, or unexpected fields. Details identify the offending input.

503
INFERENCE_UNAVAILABLE

The runtime could not produce a result. Internal exceptions are not returned to clients.

200 / 503
/health

Reports whether the model runtime is available.
